## 3. 当前对 48% 的定性

```
v6 48.0%  vs  规则 AI 46.7%
diff -1.3pt，CI [-7.7, +5.1]，t = -0.41
→ 统计上无法区分。禁止写成"打赢规则 AI"。
```

**更重要的限制**：agent 只接管了 `engine/ai.py` 里 9 个决策接口中的 1 个（`use_phase_action`：出哪张牌 + 过牌）。其余 8 个全部走规则 AI：

```
respond / save / wuxie / choose_discard / choose_card_from /
choose_one_of / choose_effect_option / choose_steal_targets
```

**所以"追平规则 AI"近似同义反复：换掉的那一块追平了原来的那一块，身体还是规则 AI。**

这不是性能天花板，是**架构天花板**。继续加训练时长不会突破。

---

## 4. 两条已被证伪的路线

| 对照 | 结果 | 含义 |
|---|---|---|
| taskB 纯模仿上场 | 8.3% | 监督模仿在对抗评估下现原形 |
| taskC 替换座位序选目标 | -6.3pt（CI 全负，显著有害） | 同上，且比简单稳定规则更差 |

**结论：不是"这些决策不重要"，是"监督模仿模块在对抗评估下不可靠"。** 后续扩动作空间必须走 RL 端到端。

---

## 5. 当前路线（里程碑）

```
M0  定基准：固定一组强对手 + 统一评估协议（见 docs/protocol/）
M1  完整动作空间：接管剩余 8 个接口，对手仍用固定规则 AI
    出口判据：统一口径下显著 > 48%
M2  自对弈 / PFSP：对手池 = 历史自身 + 当前自身
    出口判据：对固定锚定对手胜率单调上升、不塌
M3  规模化：CPU 多进程 actor + GPU learner，100 万局量级
```

**每次汇报只回答：当前在哪个里程碑、出口判据满没满足。** 除非某个出口判据被明确证伪，不重新讨论方向。

## 6. 论文口径提醒

`v2-outline.md` 是 2026-11-02 的骨架，其中 **4.4 节方法描述已过时**（tau、reward、pass、n-step、判罚全变了），**5.5 节仍标"待填"**。

另外核心叙事需要统一：

```
阶段 1（监督）：argmax 44% < 采样 66%  → 锁死 argmax 会塌陷
阶段 2（RL）：  argmax 48% > 采样      → argmax 才是正确口径
```

**统一的解释**：监督目标学的是"教师动作分布"，取 max 就锁死在"最像教师"那张；RL 学的是 Q 值，取 max 本就是正确用法。同一个操作在两种训练目标下作用相反——这不是矛盾，是需要在正文里显式讲清楚的一层。

**44% / 66% 这组数尚未在本协议（配对 / argmax / stall / A/A）下重测，重测前不得作为 v2 核心结论。**
