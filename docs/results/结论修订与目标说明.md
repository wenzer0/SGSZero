## 3. 当前对 48% 的定性

```
v6 48.0%  vs  规则 AI 46.7%
diff -1.3pt，CI [-7.7, +5.1]，t = -0.41
→ 统计上无法区分。禁止写成"打赢规则 AI"。
```

**更重要的限制**：agent 只接管了 `engine/ai.py` 里 9 个决策接口中的 1 个（`use_phase_action`：出哪张牌 + 过牌）。其余 8 个全部走规则 AI：

```
respond / save / wuxie / choose_discard / choose_card_from /
choose_one_of / choose_effect_option / choose_steal_targets
```

**所以"追平规则 AI"近似同义反复：换掉的那一块追平了原来的那一块，身体还是规则 AI。**

这不是性能天花板，是**架构天花板**。继续加训练时长不会突破。

## 7.1 48% 的定性不变，但"打平的是什么"要说清

```
v6 48.0%  vs  规则 AI 46.7%，diff -1.3pt，CI [-7.7, +5.1]
```

**统计上无法区分**。第 3 节说它近似同义反复，仍成立；筛选阶段又补了一层：
9 个决策接口的老师行为几乎全是**常数或确定性硬编码**（`choose_one_of → cards[0]`、
`wuxie` 有效点恒打、`save` 友方恒救）。**48% 打平的是一堆 if-else，不是一套强规则。**

不要由此推出"没有可学接口"——那是模仿口径的结论。老师恒定恰恰说明该点粗糙，
最值得让 RL 自己从胜负里学。

## 7.2 M1b：架构级负结果，已收口

```
出口判据（统一 argmax 口径显著 >48%）R1–R9'' 十轮未达成
C-A 全在 -2.2 ~ -4.3pt，CI 重叠；跨代同牌配对斜率 -0.23 ± 0.58，CI 含 0
```

**根因是三层架构问题，不是调参、不是方差、不是接口选错：**

1. 回报无动作项（R6 整局常数 αz / R7 时间位置函数）
2. `q_sa = mean(被选槽)` 对槽间排序零梯度（R8 梯度诊断坐实：被弃槽梯度完全相等、
   保留槽恒 0）
3. 后继价值由冻结且不分叉的 v6 头独占，target 大部分是恒定背景分

**保留三份可复用资产**：R8 梯度诊断 / R9'' 反事实协议 / 十版负结果数据。
**保留 revisit 条件**：M2 自对弈成型、动作空间扩展后有更多可训参数、
或 per-slot 损失形式被验证有效 —— 任一成立可回来重开 discard。
落档写「架构级负结果」，不写「失败」。

### 8.4 协议补强（覆盖第 7.5 节的数字）

- **跨 head 绝对比值不能当判据分母**：`0.103` 是 use_phase 路径 Q 极差，

## 9. 「改信号来源」起点作废与换载体方向（2026-11-11，覆盖第 8.2 节）

第 8.2 节写于 11-10，其「下一步 = 同一环境内改信号来源」**已作废**：desat v2 系脚本存在三层注入缺陷（对象图隔离 / 段1 rng 覆盖 / 效果栈上下文丢失——第三层为引擎模型限制），使整段否定链建立在「候选从未被消费为不同动作」的地基上。**M3 一档 35000 局主尺已确认不受影响**（策略替换、无候选注入），第 8.1 节收口仍成立；作废的只是「改信号来源」起点，两者互不纠缠。

### 9.1 v3 定案（原文写死）

> 「在单一固定后续策略的可重放点集内：`49/75` 为同名等价（本无可分辨选择）；非等价点 `26` 中有 `7` 点存在确定性候选效应，Wilson CI `[13.7%, 46.1%]`；其中仅 `2/75` 存在单侧显著唯一更优，且该优势由牌面效果可查表预测。结论：**候选维存在因果效应，但未检出需要学习的选择；可学最优决策点密度不足以支撑规模化 RL**。」限定「可重放子集、不外推全环境」。

关键读数：双遍 110 rec 一致、注入断言 PASS；`7/26=26.9%` CI `[13.7%,46.1%]`（双口径并列 `7/13≈53.8%`）；`sig_best` 由双侧改单侧 + BH 后仅 2 点（顺手牵羊 `+3 vs −3`、酒 `5` vs 杀 `4`），均为牌面效果可查表预测。`n=2` 配对比值 CI 标「样本不足、不可判」。完整链见 [M3 结果文档第 10 节](训练结果-M3-折叠层与信号密度诊断链.md)。

### 9.2 方向

**换载体**（换动作空间 / 规则集）定为方向；B 为主方向候选，**未启动**；引擎改造（选项 3）不批、记为 B 的一部分待真启动再评估；门槛不重开讨论。理由写「可学选择密度不足 + 信息多为规则先验」，**不写「候选维无信息」**（7 个确定性点否定支 2），不写「B 已批」。

下一档三条门槛跑前冻结：① 每局有效决策点 ≥ 数个；② 同一局面换动作能造成显著高于 rollout 噪声的连续量差异；③ 去掉必赢/必输局后可分辨中间态占比够高。三条不满足，换任何 loss / 网络 / 自对弈花样都是白烧。

### 9.3 协议补强（累计 33 条）

新增 6 条见 M3 结果文档第 10.5 节：身份语义对象图隔离、rng 覆盖、快照不含效果栈、`分母=0` 误剔除、双侧冒充单侧、`n=2` CI 当判据。元教训：「数字全对但判读语义错」与「验收通过但验的是别的东西」反复出现；快照 + 重放类设计必须先断言重放路径能回到同一决策点。
