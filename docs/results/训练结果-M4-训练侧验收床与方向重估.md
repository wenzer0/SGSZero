# 训练结果 M4 · 训练侧验收床与方向重估（2026-11-12 ~ 11-13）

> 本档**不是训练成果档**。这一档没有产出更强的策略，产出的是三样东西：
> 一把被校准过的尺子、一次训练器健全性验收、以及一条反复复发的元模式。
> 结果文档按时间保留原貌，不回改上文；本档独立成篇。

## 0. 一档结论（先给，措辞即结论的一部分）

1. **三国杀 2v1 简化载体的封死证据被加强，但附一层限定**：零分布校准显示
   观测 > 置换 P99 占比仅 `5.6% / 2.7%`（CI 上界 `6.5% / 3.4%`），
   「杠杆上界 16–24pt」正式作废。统一写法：
   「**未检出高于噪声地板的因果杠杆**（零分布校准：观测>置换P99 仅 5.6%/2.7%）」。
   附限定：「**该判定所用尺子的 50% 刻度未经阳性验证，证据效力降级为
   测量功效不足、不可判**」。不写「② 无可分岔」「未检出可分岔策略空间」。
2. **尺子有分辨力，刻度无效**：Connect-4 阳性对照 `D2 已知对错 35.6% [26.4,45.9]`
   vs `D1 随机 9.2% [5.2,15.7]`，两 CI 不重叠、差约 26pt。
   未过的是拍脑袋定的 `≥50%` 门槛，不是尺子坏了。**禁止因此降阈值放行**。
3. **训练器只有半条通路被验证**：最小健全性检验在合成标签上
   固定 holdout `acc 99.79% / CE 0.0435`（三次一致）、训练 `acc 100% / loss 0.019–0.024`、
   grad `5.4→0.1` 递减、`‖Δθ‖/‖θ₀‖ 0.186–0.193` → **监督拟合通路健全**。
   但 RL 特有部件（reward 赋值、return、策略梯度符号、replay、目标网络、自对弈对手）
   从未经健全性验证；R 臂 `grad_norm 159–230 大而不减` 的疑点未被排查。
   **只能写「监督拟合通路健全」，不能写「训练器/训练管线健全」**。
4. **元模式（本档最值钱的一条）**：反复失败的根因不是容量、不是算法、不是奖励，
   而是 **设计者给本来没有答案的局面规定了答案** —— 三国杀里的 `score / clue /
   身份判定`、隐藏身份切片的 `oracle = score argmax`、Connect-4 里的
   「无威胁局面 = 中列偏好」标签，是同一件事。模型每次都学得很到位
   （S 臂熵 `1.8828 → 0.098–0.117`、无威胁层 `100%`），只是学的是我们写的那个规定，
   一到真要判断的局面就失效（有威胁层 `26.7%`）。**不是学不会，是学得太忠实**。
5. **「换研究对象」裁决已撤回（2026-11-13 14:45）**：该方向由本会话在
   11-13 逐轮裁定，**用户从未拍板**，且属概念外扩 —— 把「强 AI 目标不动」
   逐步读成了「三国杀这个限定词可以去掉」。用户对本仓库的定位从头到尾是
   「三国杀自动决策与出牌 AI」。**题目不变：SGSZero 继续是三国杀 AI 项目，
   仓库不改名、不删档、不转向。** 本档因此重新定性为 **诊断方法论档**，
   不是转方向档；下文残留的「换研究对象」表述仅作历史记录，不构成当前方向。
   被证伪的只是「2v1 简化载体 + 确定性 if-else 老师 + 设计者手写答案」
   这一套组合，**不是三国杀这个游戏本身**。完整规则集 / 真人谱路径从未
   被真正训练过，不构成负结果。

## 1. 这一档要解决什么

M3 全链收口后有一个悬空问题：十几轮「未检出」全部来自环境侧测量，
**从未验证过「环境里真有信号时，我们的训练代码能不能学出策略」**。
若尺子恒阴性、或训练器本身有硬 bug，则所有「未检出」结论都分不清是
「世界没杠杆」还是「我们测不出 / 学不出」。本档就是补这两个阳性对照。

## 2. 杠杆上界外推及其作废（11-13 上午）

| 项 | 读数 |
|---|---|
| 每点「最好 vs 最差候选」终局 hp 差 | 3 人局 P50 1.27 / P90 2.23；4 人局 1.57 / 2.57 |
| 差值 >0 点占比 | 99.8% / 100%；24 组合 P50 全 ≥1hp |
| 按 M0-P0「10pt/1hp」线性外推 | 中位 13–19pt / 16–24pt 胜率 → 曾判「值得投真人谱」 |

**不批该结论**，四处：① `max−min` 是极值统计，跨候选取极值被有限 rollout
噪声系统性抬高，且 2 候选 `1.27` → 3 候选 `1.57` **随候选基数上升**，
是 order statistics 在真效应为零时的行为，不是剂量信号；② 与全链读数
（同牌配对主尺上界 `+1.2pt`、达标点 35–43%、sig_best 6–13 个）差一个数量级；
③ `10pt/1hp` 是**不同强度策略之间**的胜率弹性，套到「同局面换一个目标」
是因果层级错配，且 hp→胜负是阈值非线性；④ 与「② 因未检出因果杠杆封死」
逻辑不自洽。

## 3. 零分布校准（纯离线，已落盘数据）

| 项 | 3 人局 | 4 人局 |
|---|---|---|
| split-half 同候选伪 `max−min` P50 | 1.467 | 1.933 |
| 观测 `max−min` P50 | 1.267 | 1.567 |
| 观测 > 置换 P99 占比 | **5.6%** `[4.8,6.5]` | **2.7%** `[2.2,3.4]` |
| 观测 > 置换中位占比 | 59.2% `[57.4,60.9]` | 53.8% `[52.0,55.6]` |
| 无偏 `best−mean` P50 | 0.611 | 0.761 |

判据：`≥50%` 才认杠杆真实存在 → 未达。**「杠杆上界」= 极值统计噪声**，
② 封死结论被加强。两处落档不用于翻案：观测 > 置换中位占 59.2%/53.8%，
准确含义是「有微弱效应但幅度远低于噪声地板、未达可学门槛」，不是纯零效应；
split-half 含样本量效应（15/15 半样本方差约为 30 次均值的 √2 倍），
故「观测 < 噪声地板」不能单独作无效应证据，主判据只能是置换 P99 占比。

**准入门槛固化**：`src/train/diag_leverage_gate.py`（split-half 噪声地板 /
完全随机置换零分布每点 ≥200 次 / 观测>置换 P99 占比 + Wilson CI /
无偏 best−mean 分布），回归校验 4 人局 `2.6%`、3 人局 `6.1%`，与人工一致。

## 4. 阳性对照：尺子会不会报「有」（Connect-4）

| 组 | 观测 > 置换 P99 | CI |
|---|---|---|
| D2 已知对错 90 点（`win_now` / `must_block`，地面真值=规则判定） | **35.6%** | `[26.4,45.9]` |
| D1 随机 100 点 | **9.2%** | `[5.2,15.7]` |
| 三国杀 3 人局 / 4 人局 | 5.6% / 2.7% | — |

两 CI 不重叠、差约 26pt → **尺子有分辨力**；没过的只是 `≥50%` 这条无校准
依据的刻度。结论：分辨力有效、`50%` 刻度作废；依赖该尺子的「未检出」
一律降级为「**测量功效不足、不可判**」，**不翻案为「有信号」**。

首次有地面真值，量化「测量设计吃掉多少杠杆」：正确列占最大 `60%`（真值）
→ 检出 `35.6%`、随机 `9.2%`，传递效率约 44%；根因是随机后续 rollout
稀释单步优势（40% 点位被随机拖散），与全项目「老师后续不响应候选差异」同病。

**重审清单被砍**：隐藏身份切片（靠 b 消融 `B−A = −0.8/−2.5` +
oracle 由构造给出）、老师熵化（靠 sig_best/unpred 计数 + 双条件 + 随机基线）、
M3 一档主尺（同牌配对 + CI 上界）**均不依赖这把杠杆尺子，维持原判**。
只把用置换占比 / 配对比值判「未检出」的那批降级。

## 5. Connect-4 端到端管线验收（R 臂）

`c4_train.py`：8647 参 MLP + REINFORCE，agent 恒先手（训练/评估同分布），
混合对手 70% 随机 / 30% 启发式，N=300 对换手配对，双 seed。

| 判据（冻结） | seed1 | seed2 |
|---|---|---|
| vs 随机基线 ≥90% | 63.8% `[59.9,67.6]` | 61.2% `[57.2,65.0]` |
| vs 启发式 ≥55% 且 CI 下界 >50% | 2.7% `[1.6,4.3]` | 2.2% `[1.3,3.7]` |
| 训练曲线单调上升 | 非单调（epoch30 69–70% 后 57–67% 晃动） | 同 |
| A/A 0 不一致 | 0/30 | 0/30 |

三个实现缺陷已修：训练/评估同分布、评估 `deterministic=True`、
A/A 改确定性启发式基线。归档措辞为「**未检出该配置在 Connect-4 上的策略改进**」，
不写「管线坏」「模型没学到东西」。

**不批「训练管线是瓶颈」**：小 MLP + 稀疏终局奖励 + 无 replay/critic/
自对弈/MCTS + 120 epoch 学不动 Connect-4 是标准结果；70% 随机对手下
随机策略本就有约 55–60% 胜率，没有压力学「堵三连」。缺参数位移 / 策略熵 /
动作分布 KL，无法区分「梯度没传」与「奖励无效」。

## 6. 能力分解与最小健全性检验

### 6.1 第一次 S 臂（判据错配，判定作废）

S 臂 `hidden=128 MLP × 150 epoch`，行为克隆 `win_now/must_block` 标签：
vs 启发式 `11.3% / 11.7%` FAIL、loss `0.799 / 0.870`、熵 `0.874 / 0.909`、
位移 L2 `1.30 / 1.20`。曾判「S 也学不会 → 网络/表征/标签问题」。

**该判定作废**：把「S 学会」写成「对启发式 ≥55% 且 CI 下界>50%」是错的 ——
S 学的是老师本人的动作，复现到位后与老师换手对打胜率应在 **50% 附近**，
不可能稳定打赢自己模仿的对象（与「B 下界 > R 上界」同型，裁定方第二次犯）。
但 `11%` 离 50% 差约 38pt，判据错不等于翻案：准确表述是
「S 明显未拟合上，失败原因尚未定位」。

同时纠正：`loss 0.8 → 平均正确概率 45%` 换算不成立（`e^(−CE)` 是几何平均，
不是算术准确率；7 类均匀 CE = ln7 ≈ 1.946）；熵 `0.874` 若 nat 相对 1.946
已相当尖锐，「未确定性化」判反了；位移 `1.30` 缺 `‖θ₀‖` 分母无判据。

### 6.2 最小健全性检验（唯一动作主实验）

| 项 | 读数 |
|---|---|
| 合成标签（全覆盖无歧义）训练 | acc 66% → 100%（epoch 100+），loss 0.019–0.024 |
| 固定 1000 样本 holdout（决定性） | **acc 99.79% / CE 0.0435**（<0.05），三次一致 → PASS |
| grad_norm | 5.4 → 0.1 递减（非 R 的 159–230 大而不减） |
| `‖Δθ‖/‖θ₀‖` | 0.186–0.193 |
| 初跑名义 FAIL 98.58% | 300 样本随机重采样抖动（差 1–2 样本），固定 holdout 重估消除 |

→ **监督拟合通路健全**。按「过」分支就地改标签定义一次、重跑 S 一次。
初跑 FAIL → 换固定 holdout PASS 的过程完整落档；不算事后救判据
（训练 acc/loss 已独立过线），但不得只留 PASS 不提过程。

### 6.3 S 臂重跑（正确主尺 = 分层动作一致率 ≥90%）

| 层 | 一致率 | n | 说明 |
|---|---|---|---|
| 无威胁层 | **100.0%** | 237 | 中列偏好标签 —— 网络完全学会 |
| 有威胁层 | **26.7%** | 131 | `win_now/must_block` 目标 7 列均匀分散 —— 未学会 |
| 全体 | 73.9% | 368 | 主尺（≥90%）FAIL |
| 辅尺：与启发式换手对打 | 10.3% `[8.1,13.0]` | — | 显著低于 50% |

补报四项：① 标签覆盖率 —— `win_now/must_block` 明确状态 `36.4%`（99/272），
无威胁 `63.6%`（其余 = 中列偏好，**标签确定而非欠定**，「欠定」假说被证伪；
`build_threat vs heuristic_act` 冲突仅 12%，win_now 目标列 7 列均匀 22–45）；
② S/R 架构**不同**（S=17287 参 hidden128 vs R=8647 参 hidden64）
→ 单变量能力分解前提破裂；③ 熵单位 nat：初始 1.8828、最终 0.098–0.117、
ln7=1.9459；④ `‖Δθ‖/‖θ₀‖ = 0.081–0.193`，S grad 首 5.4 末 0.1 递减。

**根因定性（比「类别不平衡」深一层）**：网络、优化器、表征、容量全部排除后，
`win_now/must_block` 在无威胁局面根本没有定义动作，数据管线给它补了一个
「中列」标签 —— 这是**设计者给本来没有答案的局面规定了答案**。网络忠实把
这个规定学到 100%，在真正需要判断的有威胁局面失效。写成「标签类别不平衡」
会误导成「平衡采样 / 加权重就能修」；拉平采样后那个「中列」仍是人为注入的答案。
**根因是注入，不是比例。**

三处读数别当独立证据：① 辅尺 10.3% 是主尺 73.9% 的推论，不是第二条 FAIL，
列作辅证防重复计数；② 有威胁 `26.7%` 与「中列恰为 win_now 列」的
`1/7≈14.3%` 对不上，纯中列捷径不能定量闭合（可能混入 must_block）；
分母 `180 / 272 / 368 / 131` 属四批不同样本，须逐数标出处。

## 7. 收床与两条准入硬约束

**收床写死**：健全性检验 + 一次标签修正重跑 = Connect-4 验收床终点。
无论读数如何，此后不再在 Connect-4 上做任何诊断 / 切片 / 加 epoch /
换配置 / 平衡采样重训。Connect-4 只是**管线验收床，不是研究对象**。

带进下一档的两条硬约束（跑前冻结）：

1. **监督信号必须由环境 / 对局结果给出；禁止给无分岔局面补设计者规定的答案。**
   本档已证：补了就会被忠实学会（100%），并在关键局面失效（26.7%）。
2. **任何臂对照必须锁同一网络并报参数量**，否则不构成单变量分解
   （本档 S=17287 / R=8647 即反例）。

下一档准入读数（**候选全部限定在三国杀题目内**：完整规则集接入 /
真人谱采集 / 完整规则下自对弈；不得把 GunZ、TPS 沙盒、Atari 等外部题目列为候选）：
对候选各给五个数 ——
每局有效决策点数（含「有效」定义与样本局数）、决策→结果杠杆
（**只报有地面真值对照的相对分离度与两组 CI 是否不重叠**；
`观测>置换P99 ≥50%` 刻度已随阳性对照失败作废，禁止再用它放行或否决）、
监督信号由谁给出、是否需设计者手写「什么是对的」、可复现基线来源。
给不出数的格写「该候选不可判」并换候选，不许用「待采 / 待算 / 就绪」占位。

## 8. 方向状态与归属（2026-11-13 14:45 重新裁定）

**先撤回两处概念外扩**：

1. **「换研究对象」撤回**（见 §0.5）。本仓库题目始终是三国杀 AI。
2. **「② 完整规则集封死」撤回，改为「简化载体封死」**。11-12~11-13 那批
   目标维度补测 / 4 人局扩样，跑的全是**当前 2v1 简化引擎 + 补一个
   `legal_targets` 接口 + 把人数从 3 扩到 4**；引擎里虽有 31 武将 / 52 技能位 /
   161 牌的资产，但**从未接入训练决策点**。用简化载体的读数给
   「完整规则集」判死刑，与用 Connect-4 给三国杀判死刑是同一类错误。
   同理，M2 自对弈负结果、老师熵化负结果、隐藏身份切片负结果，
   **全部局限于「简化 2v1 + 确定性 if-else 老师 + 设计者手写答案」这一载体**，
   不外推到完整规则集 / 真人谱 / 多策略自对弈。

| 路径（均在三国杀题目内） | 真实状态 |
|---|---|
| 简化 2v1 载体 + 常数老师 + 手写答案 | **封死**：`5.6% / 2.7%` 杠杆校准、效应在 ±1.5pt 内；这是本项目实际跑过的全部训练 |
| 完整规则集 + 武将技能组合（31 武将 / 4495 三人组合 / 52 技能位 / 161 牌） | **未测**：资产在引擎里，从未接入训练。不是负结果 |
| 真人 / 高质量人类对局谱 | **未测**：真人局 0 局，瓶颈是外部采集，不是「谱无效」 |
| 自对弈共同演化 | **在简化载体上负结果（M2）**；完整规则集下未测，不外推 |
| 换研究对象（11-13 把关会话裁定） | **已撤回，用户从未拍板** |

**一句话定性**：到今天失败的是一个**降规模原型**，不是三国杀 AI 这个项目。
把原型失败写成项目失败，是本会话在 11-13 犯的最大的判断错误。

目标维度补测的两遍读数：`257,460 / 258,000` rollouts 100% 真正打完、`stall=0`；
4 人局扩样 `258,599 / 258,564` 打完、合法目标数 `{2:34, 3:86}`（`≥3` 占 71.7%）
证实候选基数限制已解开。达标点占比 3 人局 35.3%/35.9% → 4 人局 42.1%/43.0%，
是唯一正向剂量信号，但 `sig_best 9/13 → 6/6` 未随之上升（疑与总 rollout 预算固定、
候选 2→3 摊薄每候选 CRN 有关，**仅作方法学疑点，禁止当「再跑一次就能过」的理由**）。

**引擎侧真实资产**（静态审计 73 函数）：`ai.py` 的 `_sha_targets / _trick_targets`
用 `sha_target_score / discard_target_score / hp / countCards` 打分，
目标选择决策面与 RuleAI 启发式焊死，剥离启发式后无独立目标接口。
已补 `legal_targets(game,p,card)->list` + `legal_use`（零打分、无排序、
不写「什么是对的」），静态验真非空 200/200，带真实目标 `use_card` 成功 136 次
（`winner=zhu, rounds=6, stall=False`）。这是「引擎缺一个能力」而非信号 /
算法 / 判据问题，也是本档少数可复用的工程产出。

## 9. 本档新增口径陷阱（10 条，累计 43 条）

| # | 陷阱 | 一句话 |
|---|---|---|
| 34 | 极值统计冒充因果杠杆 | `max−min` 随候选基数增大是 order statistics 在零效应下的行为 |
| 35 | 策略间弹性外推到同局面内 | `10pt/1hp` 是不同强度策略间弹性，套到单次决策是因果层级错配 |
| 36 | 尺子未做阳性对照 | 对任何任务都返回阴性时，「世界没杠杆」与「尺子恒阴性」不可分 |
| 37 | 拍脑袋阈值 | `≥50%` 无校准依据；不可因结果不好而降阈值放行 |
| 38 | 「打赢老师」当行为克隆判据 | 模仿者不可能显著强于被模仿者，期望值约 50% |
| 39 | CE → 准确率错误换算 | `e^(−CE)` 是几何平均，不是算术准确率 |
| 40 | 「训练器健全」外推过宽 | 合成标签过拟合只证监督通路，不证 RL 特有部件 |
| 41 | 架构不同冒充单变量分解 | S=17287 / R=8647，能力分解前提破裂 |
| 42 | 无分岔局面补设计者答案 | 元模式：模型忠实学会规定，在关键局面失效 |
| 43 | 换口径消解 FAIL / 辅尺重复计数 | 初跑 98.58% → 固定 holdout 99.79% 须落全过程；辅尺是主尺推论非独立证据 |

元教训两条：「**数字全对但判读语义错**」与「**验收通过但验的是别的东西**」
在本档继续复发；以及本档新加的一条 —— **没有阳性对照的判据不具备否决权**，
而「模型学得太忠实」比「学不会」更难被发现。

## 10. 措辞红线与边界

- 不写「B 已批」「环境固有」「无杠杆」「一切无可学空间」「模型没学到东西」
  「② 无可分岔」「未检出可分岔策略空间」「其实都有信号」「管线坏」「S 也学不会」。
- 三国杀简化载体统一写「**未检出高于噪声地板的因果杠杆**（零分布校准
  5.6%/2.7%）」+「**该判定所用尺子的 50% 刻度未经阳性验证、证据效力降级为
  测量功效不足、不可判**」。
- M3 一档只写「**±1.5pt 内未与 0 区分**」；「改信号来源」起点收口作废，
  与 M3 一档互不纠缠。
- 阶段 2 只写「48.0% vs 46.7%，统计上无法区分」，禁止写「打赢规则 AI」。
- **强 AI 目标不动，「三国杀」这个题目限定也不动**。「换研究对象」裁决
  （11-13 把关会话作出、用户未拍板）已撤回；`SGSZero` 继续是三国杀 AI 项目，
  仓库不改名、不删档、不转向。v1 论文、CITATION、早期结果文档按时间保留原貌。
- **禁止把这些负结果写成「三国杀 AI 做不成」**。被证伪的是简化 2v1 载体、
  确定性 if-else 老师、以及「设计者给无分岔局面手写答案」这套做法；
  完整规则集 / 真人谱 / 完整规则下的自对弈从未被训练过，不构成负结果。
  本档的价值是**排除了三类不该再重复的做法**，不是给题目判死刑。
