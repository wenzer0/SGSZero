### 定性（不能写成"打赢规则 AI"）

1. **CI 太宽**：diff -1.3pt，CI 宽 12.8pt → **只能写"统计上无法区分"**。

2. **v6 的身体是规则 AI**：选目标/闪/桃/无懈/弃牌全部规则 AI。
   它只是在"出哪张牌"上追平了手写规则——是"AI 学会了规则的选牌"，
   不是"AI 打赢规则"。
3. **8 小时训练不会突破**：已把手写规则在选牌上的知识学完，再训只磨得更稳，
   不会多出动作维度。

## 三、v4 倒挂 = Q 膨胀 artifact（非真退化）

- v2 19.3% → v4 13.3%（argmax 下倒退，采样口径下 v4 反而最高）
- 根因：**v4 的 Q p90=5.1（reward 才 ±2）——高估膨胀**
- 采样（tau=0.1）分散掩盖膨胀 → v4 采样 28.7% 全场最高
- argmax 直接暴露 → argmax 选到"虚高但错误"的动作 → 13.3% 全场最低

## 四、方法学发现（论文 Analysis 素材）：argmax 是 Q 质量的探针

> 采样评估（tau=0.1）系统性掩盖价值函数的缺陷；argmax 直接暴露。
> 温度采样会掩盖"Q 高估膨胀"这类问题——评估价值函数质量必须用 argmax。

同一模型三个数（v6）：
- 训练窗口累计 23%（含早期差局，低估）
- 配对采样 24.7%（仍被随机性分散）
- **argmax 48.0%（真实贪心能力）**

## 五、教训（写入纪律）

1. **A/A 测试验证"可复现"≠"正确"**：nan bug 让 argmax 固定出第一张牌，A/A 100% 通过
   （它是确定性的），但确定地错。改评估口径必须加健全性检查（打 10 局人工看牌"像不像样"）。
2. **deepcopy 必须最先执行**（paired_eval 曾经 deepcopy 前消费共享 rng → 配对失效）。
3. **评估口径 = 部署口径**（argmax；tau 采样只在训练用）。
4. 跨版本对比必须同口径终评（绝不用训练窗口累计数）。

## 八、当前方向决策（用户拍板）

1. **响应阶段（1-2 周）暂不投**——若做必须 RL 端到端（模仿会重蹈覆辙），更贵；
   评估尺子刚修好、报告未固化，此时开大工程风险最高
2. **有便宜 20 倍的替代：1-ply lookahead**——Q 有信号（AUC 0.845 方向可信）、
   Q 膨胀已修（p90 1.89 ≈ reward ±2）、不改训练不加动作空间、deepcopy 地基就绪
3. **前置验证（半天）**：响应决策频率 / 规则 AI 响应与弃牌失误率 / 1-ply lookahead 对照
4. 出结果前：不投 1-2 周、不启动 8h 训练

## 十五、M1a-1 修复重测（2026-11-05，作废旧数）

### 根因：候选槽超出 hp 实际有效位置
- `_enc` 的 hp 恒 24 维，但有效 token 位置只有 `n_valid=(hp_abs>=0).sum()` 个（如 20），
  其余填 -1；旧代码候选上限用 `min(len(hand_sorted),24)` → 候选槽落进 -1 掩死槽
  （q 被 -1e9 mask），label 撞上即 loss 爆炸（1.7 亿-3 亿，acc≈随机）

### 五处修复全列（2026-11-07，复盘防重查）
| # | 修复 | 落点 |
|---|---|---|
| ① | 候选位置改**绝对 token 位置 hp_abs**（两侧同构），并加越界断言 `cand_pos < t.size(1)` | 采集 collect_respond/collect_discard + 推理 respond/choose_discard |
| ② | argsort 改 **descending**，与 CE 方向对齐（旧 ascending 弃的是"最不该弃的"） | sg2_train.choose_discard 推理 |
| ③ | **n_valid 封顶（根因）**：候选数按 `n_valid=(hp_abs>=0).sum()`，respond 不加槽 n_cand≤n_valid+1、discard n_h≤n_valid；label clamp 改 `n_h-1` | 采集 2 处 + 推理 2 处 + label clamp |
| ④ | 标签序号改**按规则弃牌顺序取第一张**（旧 next() 同名可能指向不同张，序错位） | 采集 collect_discard |
| ⑤ | respond「不出」负例补真实 label：先调 `orig_respond()` 拿 r_ok 再定 label（旧 `if cands` 隐含恒出 → 91% 常数假象） | 采集 collect_respond |
- 复验：0 个 -1 坏槽；decline 槽恒在末位且 = -2（方案 C 合法语义）；label 全合法

### 重采 300 局 + 重训
- 样本：respond 5148 / discard 17403 / 总 22551
- 重训 10 epochs（GPU 94s）：loss 1.0-2.0（爆炸消失），acc 37.5% → 41.4%
- 旧数作废：91%（常数标签假象）/ 77%（label 序错位）/ +1.7pt（旧头）一律不再引用

### 逐点一致率（修复后重测，含基线）
| 头 | 命中 | 常数基线 | 随机基线 | 平均候选 | dt消融差 |
|---|---|---|---|---|---|
| respond | 86.3% | **91.2%** | 30.3% | 3.3 | +5.0pt |
| discard | 45.3%* | 24.7% | 6.3% | 15.8 | +9.0pt |
- respond = 未超常数（-4.9pt）→ 按用户纪律判「respond 未学到」（原因见下节：目标信息量问题）
- *discard 45.3% 只是**「第一张命中率」**：训练只监督弃牌集合第一张（单标签 CE），部署要选
  num 张，其余 num-1 张相对顺序无梯度 → **⑥「discard 目标定义」未做，45.3% 不作数**；
  且样本无 num 字段，模型不知道要弃几张（多选子集须改 top-k 排序损失/逐牌二分类）

### respond 错分结构（为什么只差 5pt）
- label 91.8% 是 0（出第一张匹配牌）；模型对「出」样本 10.1% 乱选到高槽，
  对「不出」样本 53.3% 打成出 → q 噪声把本该 91.2% 的常数任务拖到 86.3%
- 尝试单变量 `--resp-w 10` 加权负例 → respond 79.5%（更差，dt 消融归零）→ 加权不解决，
  问题在模仿目标本身信息量低（规则 respond 行为 ≈ 常数「出第一张」）

### respond 整局配对非劣（600 对，m1a_ws_head2.pt）
- diff = +0.007 | 95%CI [-0.015, +0.028] → CI 下界 ≥ -2pt ✅（双条件满足：点估计≥0 且 N≥600）
- 绝对胜率：A(规则 respond) 47.5% | B(M1a respond) 48.2%
- stall：A 11 (2%) / B 9 (2%)；赢局均轮 22.7 / 23.1
- **respond 触发：A 7905 (13.2/局) | B 8202 (13.7/局)** → 高频上场（M1b 算力必须考虑）
