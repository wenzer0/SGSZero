## 0. 一档结论（先给，措辞即结论的一部分）

> **折叠层从动作空间表示层结构上解决了「等价候选不可分」问题，但 35000 局训练未在候选级决策上转化为可测胜负增益（效应落在 ±1.5pt 内）；随后对候选目标、信号密度与环境规模的系统排查，把下一档方向收敛到「同一环境内改信号来源」。这是一档训练的负结果，不是方向性失败。**

禁止写成：

- ❌「打赢规则 AI」/「RL 带来提升」——阶段 2 的 48.0% vs 46.7% 只能写**统计上无法区分**；
- ❌「模型没学到东西」/「无效果」——35000 局主尺是 `+0.4pt, CI ±0.8, 上界 +1.2pt`，含 0 也含小正增益；
- ❌「有证据横盘」——全局辅尺是**未达精度、结论不可定**；
- ❌「三国杀 AI 做不出来」——环境策略敏感度实测 10–17pt，问题在策略来源，不在环境对策略不敏感。

## 1. 这一档要解决什么

阶段 2 之后，agent 只接管 9 个决策接口中的 1 个。M3 的目标是把决策级学习信号扩到其余接口，并验证「折叠后策略能否转化为胜负」。

前置条件（起跑前全部验证通过）：

| # | 判据 | 结果 |
|---|---|---|
| ① | `c_scale` 固定且冻结可验证 | ckpt 携带 `{0.693, 0.693, 1.609}`，dict 非 Parameter、不在 optimizer，全程恒定 |
| ② | 异常 0 + 三计数口径自洽 | `done == att`、`exc {}`，无「异常 0 又 n_done 少计」并存 |
| ③ | 速率定准 + 10 万局上界 | 分离口径 17925 局/h、端到端 11832 局/h 分字段落盘；上界 8.88h + 20% = 10.66h ≤ 14h |
| ④ | Q 贡献探针 | dt=4 候选 Q 的 argmax 翻转 23/66 = 35%、Q 逐点差 2.22 —— 增量头确实改变决策 |
| ⑤ | 护栏 + 断点演练 | 心跳 200 局 ≠ ckpt 5000 局双门槛、kill + resume 重试 3、电源/磁盘/显存；2000→5000 局演练六项全过 |
| ⑥ | 终点协议写死 | 同 seed0 配对、McNemar 类 CI、半宽 >1.5pt 自动追加、A/A 校验 |

口径修正落档：`Δθ/θ` 对零初始化起点层无意义 → 改用**绝对位移**；Q 极差首版测错路径（`use_phase` 本不该动）→ 改测 dt 路径；`T_ckpt` 为写缓存口径 32–37ms；速率三口径分字段不混。

## 2. 三次同根：候选间没有可学的差别

| 档 | 现象 | 根 |
|---|---|---|
| M1b | `q_sa = mean(被选槽)` 零槽间梯度，被弃槽梯度完全相等 | 梯度无候选条件 |
| M2 | 增量头只有 25 维常数，容量不足以表达状态条件 | 表示容量不足 |
| M3 | 同名牌不同 `hand_pos`（两张【杀】→ pos 17 vs 26）经 encoder 后**表征 pairwise 距离 = 0.0000** | 输入表征层不可分 |

**M3 候选侧审计**（frozen 35000 / 固定 probe 池 / `cp≥0` 排除 decline）：

| 接口 | 候选≥2 状态 | 候选间 Q 跨度 | 候选 token 表征 pairwise |
|---|---|---|---|
| save (dt3) | 8/27 | 0.0000 | 0.0000 |
| wuxie (dt4) | 3/27 | 0.0000 | 0.0000 |
| card_from (dt5) | 35/40 | 0.8463 | 34.02（真实差异） |

机制闭环：save / wuxie 的候选多为同名牌（两张【桃】/ 两张【闪】）→ 表征只看 token 内容、位置信息在 norm/无位置编码下丢失 → 增量头唯一可学自由度是**共同平移** → `delta` 膨胀到 127.4（症状）、Q 跨度恒 0、共同平移占比 100%、argmax 退化为平局打破机制。card_from 的候选是异牌混合（杀/桃/锦囊）→ 表征有差异 → 同一增量头学出真实差异 0.52。

**关键定性**：出【桃】A 还是【桃】B 在状态转移上完全等价，Q 本就该相等，跨度 0 是**正确结果**。根因不是「表征丢了位置信息」，而是**动作空间建模把 MDP 中同一个动作拆成了多个名义候选**。因此补位置编码 / 给等价候选强加区分是有害的（会制造固定选某个 hand_pos 的虚假偏好），限幅度（clamp / tanh）也压不出候选差异。

## 3. 折叠层（结构性解法）

不按接口硬摘，而做通用**等价候选折叠层**：动作构造时按候选 token 多重集判断同质 → 同质折叠为单动作 / 仅 decline 二元，**不进候选级 loss**；异质保留候选级 Q。

短程验证（全部判据通过）：

| 判据 | 结果 |
|---|---|
| 折叠率符合预期 | dt3 51–53%、dt4 12–14%、dt5 4–5%（异牌保留）——按 token 多重集通用工作、非按接口硬编码 |
| 异牌组候选间差异稳定非零 | dt5 Qspan `2.51 / 4.25 / 5.87 / 3.77`，连续 4 读点稳定显著 |
| delta 不爆炸 | `d/span` 全读点 0.4–6.6x；`m1a2` grad 从 35000 局的 66–101 回落到 13.7–25.0（共同平移不再主导梯度） |
| 配对验收 / A/A | A/A 双跑 0/300 不一致 PASS（修复 `winsF = winsC` 别名赋值 bug 后完整跑通） |
| 早停双向自检 | 3/3：真实序列在 30000/35000 触发、波动反例不触发、阈值内不触发 |

**后续口径**：折叠判定宜从「token 多重集相同」升级到「**游戏效果等价**」——异牌同效果（不同花色同效果）是假可分，同名牌在不同上下文效果不同是误折叠。

## 4. 两轮 10 万局长跑与三次早停

| 轮次 | 版本 | 停在哪 | 性质 |
|---|---|---|---|
| 第一版 | 无折叠层 | 35000 局 | **真发散**：dt3 增量/跨度比 `0.7→1.2→12.7→14.4→15.1→29.7→45.6x` 7/7 严格单调且高位加速；dt5 flip 一度 65% |
| 第二版 | 折叠层 | 20000 局 | **误触发**：`Qspan/主干极差 > 30x` 的 persist 分支在「高位回落」(`56x→35x`) 时命中 |
| 第二版 | 折叠层 | 35000 局 | **误触发**：判据 c「连续 3 读点单调放大」缺绝对下限，`d/span 2.1→3.5→4.5x` 在远低于 10x 信号门槛时触发 |

**第一版排查结论**：真发散（尺度失控）+ 对照打平 → 收紧尺度/排查。排查① 直接对照 300 对同牌 `frozen(35000) vs V1 43.3%±5.6`、`init 42.3%±5.6`、配对差 +1.0（CI±3.1）打平，未坐实 v6 被冲掉；排查② 口径与机制分解见第 2 节；排查③ `m1a0 norm 13.1→116.0` 严格单调、冷启动全程无 resume，尺度失控由训练自身驱动、非污染。

**第二版两次误触发的判据缺陷（如实记录）**：

1. `30x` 阈值用了 `0.103`（use_phase 路径主干 Q 极差）当分母，而 Qspan 是 dt 路径、不同 head 不同量纲；且短程验收通过时 dt5 Qspan `2.51–5.87` 除以 0.103 本就是 `24–57x` —— **等于给正常值画了条超标线**。
2. 趋势判据写成「无条件触发」，漏了「`d/span > 10x` 且 Qspan 同步放大才升级为信号」的绝对门槛；且只有 2 个读点就判「连续 3 读点单调」，缺最小观测数。

最终判据形态：`触发 = 绝对门槛 AND 趋势确认`；绝对门槛 = `d/span > 10x` 或 `Qspan/自身基线 > 3x` 或 `flip > 60%`；趋势确认 = 连续 ≥3 读点单调放大且末值 > 首值×1.5；最小观测数 ≥3；只有趋势、绝对未达标 → 观察项不触发。**早停应只落快照 + 出诊断读数，不该自动跑完整终局定案**。

## 5. 35000 局中途锚点：三样读数

第二版在 35000 局早停后进入终局定案段（`m3_35000.ckpt` 未写脏：hash `ed9fbe03`、mtime `13:47:06`；评估只读；watchdog 已切只监控防误杀）。

| 尺 | 读数 | 判读 |
|---|---|---|
| **反事实主尺**（3000 对同牌，仅 dt 候选级替换策略、其余完全相同） | current 43.9% vs init 43.5%；`init独赢 62 / cur独赢 74 / 不一致 136`；`d = +0.4pt`，`CI ±0.8`，**上界 +1.2pt** | 「未转化胜负」严格成立（上界 1.2 ≤ 1.5pt） |
| 全局辅尺 | 配对差 +0.7pt、CI 半宽 1.6 → 追加 3540 对 → 仍 1.6 > 1.5 | **未达精度：结论不可定**，禁止写「有证据横盘」 |
| A/A | 0/300 不一致 | 管线干净 |

主尺 CI 校验：`Var(d) = (b+c−(b−c)²/N)/N² = (136−144/3000)/3000²`，半宽 `1.96×0.389 ≈ 0.76pt`。

**判读纪律**：「上界 1.2 ≤ 1.5」的准确含义是**效应落在 ±1.5pt 内**，不是「效应为零」；区间 `[−0.4, +1.2]` 含 0 也含小正增益。判据一律用 **CI 上界**（`d + 1.96·SD ≤ 1.5pt`），不用点估计。

**据此停止 10 万局**：配对评估的 CI 半宽由不一致对数决定、不由训练局数决定；再跑 65000 局只会买到一个已知上界的答案。35000 局锚点保留作后续纵向对照。

## 6. 诊断链：从「没转化」到「改信号来源」

### 6.1 诊断 A / B（第一版）

| 诊断 | 读数 | 判读 |
|---|---|---|
| A：选择质量（26 个 card_from 决策点） | frozen 与最优 rollout 一致率 13/26 = init 13/26 | 样本过小，CI 半宽约 19pt；「边际率相等」不等于配对无差别，方向仅参考 |
| B：决策点杠杆上界 | 脚本自动 verdict「b（设计天花板）」不可采信：rollout 分化仅 6/30=20%，80% 点 `out_wins` 全同，`med 0pt` 是 40 回合截断的 artifact | 有效点（20%）杠杆 = 1.0（整局胜负翻转） >> 1.2pt → b 排除 |

### 6.2 三样补测（60 决策点 / 79 局、完整局 rollout、每候选 3 次）

| 测 | 读数 | 判据归属 |
|---|---|---|
| 信号密度 | card_from 决策点/局 0.76；分化点 22/60 = 37%；有效带标签决策点/局 ≈ 0.18（<1） | 「每局 <1 个有效带标签点 → 换任何 reward 无效」命中 |
| 诊断 B 重跑 | 全样本期望杠杆 23.3pt >> 1.2pt；中位 0 / 分化点中位 100pt（skewed） | b 排除（非设计天花板） |
| 诊断 A 重做 | 60 → 未分化 38 → 分化标签 22；`frozen对/init错 3` vs 反向 1 | CI 半宽 42pt >> 5pt，不达严格口径，不作定论 |

**共同地基问题**：每候选只跑 3 次 rollout，`2:1` 与 `1:2` 的差别与噪声分不开 → 「最优」标签是噪声 argmax（winner's curse），因此「一致率低于随机 33%」是 artifact，不能推出「策略比乱选还差」；「分化点」边界本身也受污染。另：「杠杆 23.3pt」是「最优 vs 最差」全幅，「主尺 1.2pt」是「训练后 vs init」之差，**不是同一个量**——杠杆大只说明天花板够高，推不出「策略没吃到」。

### 6.3 接口普查（改学习目标的候选）

| 候选接口 | 频次/局 | 标签性质 | 判定 |
|---|---|---|---|
| 目标选择 steal | 0.57 | 近稀疏 | ✗ 频次 <3 |
| 是否发动 effect_option | 0.20 | — | ✗ 频次 <3 |
| 选一 one_of | 2.10 → 2.62 | 熵 2.80bit、MIX 异牌 50%，但 `pick0 = 100%`（老师恒选第 0 张） | ✗ 伪熵（候选集合别名，非策略信号） |
| respond（有效点） | 6.57 | 97% 恒出、近常数；监督头 96.3% vs 基线 96.9% | ✗ 无可优化空间 |

respond 的准确表述：标签天花板 97%、基线已到 96.9%，可提升空间 0.1pt；监督对齐老师本来就证明不了「没有可优化的决策」（老师恒出 ≠ 最优恒出），但 `6.57 × 3% ≈ 0.2 点/局` 密度仍极低。

### 6.4 环境预研三步（是否该换问题规模）

| 步 | 读数 | 判据归属 |
|---|---|---|
| 策略敏感度（复用 P0 / 双谱） | 极差 10.0–17.0pt >> 3pt | 环境有策略空间，**不为环境理由换引擎** |
| one_of 标签熵 | 熵达标但 `pick0 = 100%` | 伪熵，维持否定 |
| 多策略老师采样 | V2 ε 扰动 / V3 随机弃牌均未提升 respond 标签熵（0.35–0.43bit） | 根因在确定性老师，换牌池/规则集白烧 |

**口径提醒**：10–17pt 极差复用自 P0 / 双谱，而 V2/V3 是人为削弱农民的变体 —— 它证明「胜负能被策略强度影响」，**不证明「存在比老师更好、可学的策略」**。ε 扰动加出来的是次优动作而非另一种合理策略，证明不了「多策略老师不可行」，更证明不了「搜索标签不可行」。

### 6.5 综合判决

```
环境本身对策略敏感（10–17pt 极差）  → 不是「尺子不够长」
老师确定性硬编码（恒出 / 恒选第 0 张），多策略扰动也造不出分岔
                                  → 换牌池/规则集是白烧
⇒ 下一步 = 同一环境内改信号来源（反事实搜索标签 / 非确定性策略池）
           而非跨引擎 / 换规则集
```

跨引擎评估放在最后：成本最高，且只回答可复现性、不解决归因。

**起步定为反事实搜索标签 + `one_of` 接口**：候选异质（`2.62 次/局`、熵 2.80bit）+ 老师选择是常数，是唯一符合「高频 + 异质 + 老师明显不优」的试验田；先查候选顺序有无语义（按牌价值排序则 pick0 可能已最优、按手牌位置排则老师近乎随便选）。预研已备好前端（完整局 rollout、每候选 ≥30 次、CI 判显著最优、无显著最优标「无标签」剔除），只差把诊断读数转成训练标签。

第一个判据：**搜索标签与老师标签的不一致率** ≥20% → 存在可超越老师的信号，继续；<5% → 老师在该环境近乎最优，回来重拍板；5–20% → 按有效标签密度再定。rollout 后续策略必须固定并写进口径，否则估值衡量的是「在老师打法下哪张牌好」，标签仍被老师污染。

## 7. M3 新增评估口径陷阱（13 条）

阶段 2 已记 14 条（[六个陷阱](../protocol/评估协议-六个陷阱.md) 6 + [补充陷阱](../protocol/评估协议-阶段2补充陷阱.md) 8）。本轮又抓出 13 条，统一四栏：现象 / 实测量 / 判据 / 修复。

| # | 现象 | 实测量 | 判据 / 修复 |
|---|---|---|---|
| 15 | 速率单位 `*1000` 重复乘 | 报 `3063096 局/h` | 打印 `n_done / hours / t_start / now` 原始值；真实率 ≈ 3063 局/h，三种口径差 4 倍，定准前不许写「过夜可行」 |
| 16 | 混合口径外推 | `8.88h` 既含端到端评估又叠 `0.29h` | 纯训练率与端到端率分字段落盘；容量规划取保守上界 + ≥20% 余量 |
| 17 | 旧日志残留冒充当前状态 | 读点里出现「DONE」但心跳仍在推进 | 日志按 run_id 隔离，旧结果作废标记，不进汇总 |
| 18 | watchdog 心跳阈值与 ckpt 间隔冲突 | ckpt 每 5000 局 = 25.4 分钟，阈值却设 15 分钟 | 心跳与 ckpt 解耦；ckpt >60 分钟才硬告警；先切「只监控不拉起」再排查 |
| 19 | 「异常 0」与「n_done 少计」并存 | 两句自相矛盾 | attempt / done / exception(按类型分桶) 三计数器；异常真为 0 时 continue 分支不会走到 |
| 20 | 别名赋值造成 A/A 假 PASS | `winsF = winsC`（list 引用） | 修成独立列表；A/A 0/300 必须在修复后产出才有鉴别力；A/A 用不一致对数，不用胜率接近 50% |
| 21 | 点估计冒充 CI 上界 | `+1.0pt CI±2.5` 被写成「<1.5pt 未转化」 | 判据一律 `d + 1.96·SD ≤ 1.5pt`；半宽按 1/√n 反推所需对数（854 对起、上限 10000 对） |
| 22 | 边际率相等冒充配对无差别 | `13/26 = 13/26` | 报 McNemar 不一致数；26 点 CI 半宽 19pt，≥300 点且半宽 ≤5pt 才有资格说有无差别 |
| 23 | 跨 head 比值当分母 | `Qspan / 0.103 > 30x` 误标 | 0.103 是 use_phase 路径、Qspan 是 dt 路径，量纲不可比；撤掉绝对倍数作触发项，改用自身基线 + 趋势 |
| 24 | 趋势判据缺绝对下限 | `d/span 2.1→3.5→4.5x` 在 4.5x 触发 | `触发 = 绝对门槛 AND 趋势确认`；只有趋势 → 观察项不触发 |
| 25 | 单点检查 / 缺最小观测数 | 「连续 3 读点单调」用 2 个点判 | 最小观测数 ≥3；双向自检须含真实回落序列作反例 |
| 26 | 3 次 rollout 噪声标签 | 「一致率低于随机 33%」 | winner's curse 下固定策略与噪声 argmax 期望一致率低于 1/n；每候选 ≥30 次，CI 判显著最优，无标签剔除 |
| 27 | 截断造成假零杠杆 | 40 回合截断、`med 0pt` | 放开 `max_rounds` 到完整局，全样本报期望杠杆，不许只报分化子集 |

**最该记住的一条**：本项目已多次出现「验收通过但验的是别的东西」。任何自动判读文字必须与同屏数值可机械核对；方向性断言优先于输出量级比较。

### 10.1 三层注入缺陷与方向 A 语义

「改信号来源」起点的收口**已作废**——desat v2 系脚本存在三层失效：

| 层 | 现象 | 处置 |
|---|---|---|
| ① 对象图隔离 | `forced` 取自 live game、`g2=deepcopy(snap)`；`Card` 用 `__slots__` 且无 `__eq__`，消费端 `cardx in t.hand` 为身份比较 → 恒 False，三候选终局全同 `[1,1,8]` | 按 `cj` 索引取 `g2` 对象图内的牌（探针 C 通过） |
| ② 段1 rng 覆盖 | 重设 `g2.rng` 使决策点前随机流分叉（B-base 同策略锚定率仅 21%） | 保留 snap 继承的 rng 到决策点（探针 D 12/12 命中、跨 rk cid 一致） |
| ③ 效果栈上下文丢失 | **引擎模型限制**：采集点位于效果栈中间，`deepcopy` 只存世界状态，`phaseLoop` 从整回合头重跑；换后续策略族时决策点本身漂移（GreedyFollow 下 `choose_card_from` 触发 0 次、S-strong 重放命中 0%） | 非代码可修。方向 A：候选取「重放点自身」+ 段1 保留 rng + 段2 CRN 播种 |

**③ 的含义**：「采集点快照 + 换后续策略重放」这一反事实范式在当前引擎下整体不自洽，不是某个脚本的 bug。因此方向 A 的点集是**按可复现性筛过的可重放子集**，标签率不外推全环境；四档对比结构弃用；方向 A 不裁决 A/B 方向。

`M3 一档 35000 局反事实主尺`已确认**不受任何影响**（策略替换、agent 全程跑在 `g` 上、`forced` / 外部 cards 全文件 0 命中），M3 一档收口仍成立。

### 10.2 v3 定案读数

双遍 110 rec 逐字节一致、注入断言 PASS（`matched_false=0`）；110 决策点 / 61 局，可重放点 75，stall 剔除 16。

```
75 = 同名等价 49 + 确定性可区分 7 + 确定性等价 13 + 噪声>0有差 2 + 噪声>0等价 4
分母 = 非等价可重放点 26（同名等价单列阴性对照）
有信息侧 7/26 = 26.9%，Wilson 95% CI [13.7%, 46.1%]
双口径并列：7/13 ≈ 53.8%（候选可能不同的点内占比），均不外推全环境
n=2 的配对比值 CI [0.100, 0.333] 标注「样本不足、不可判」，不参与判定
```

**`sig_best` 语义修正**：原实现用双侧「显著不同」判最优，会把显著更差误判为最优（点 16 `tao hp=-3`）。改单侧「显著更优于所有其他」+ BH 全族后，7 个确定性可区分点中仅 **2 点**存在真正唯一显著更优：点 26（顺手牵羊 `+3` vs 其余 `−3`）、点 106（酒 `5` vs 杀 `4`）——**该优势由牌面效果可查表预测，不构成需要学习的策略排序**。其余 5 点候选间差 1–2 血且无唯一显著更优。

### 10.3 定案措辞（写死）

> 「在单一固定后续策略的可重放点集内：`49/75` 为同名等价（本无可分辨选择）；非等价点 `26` 中有 `7` 点存在确定性候选效应，Wilson CI `[13.7%, 46.1%]`；其中仅 `2/75` 存在单侧显著唯一更优，且该优势由牌面效果可查表预测。结论：**候选维存在因果效应，但未检出需要学习的选择；可学最优决策点密度不足以支撑规模化 RL**。」限定「可重放子集、不外推全环境」。

**方向 = 换载体**（换动作空间 / 规则集），理由为「可学选择密度不足 + 信息多为规则先验」，**不写「候选维无信息」**（支 2 已被 7 个确定性点否定），亦不写「B 已批」。B 为主方向候选，**未启动**；引擎改造（选项 3）不批；门槛不重开讨论。
