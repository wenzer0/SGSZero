# SGSZero · 零杀

> 从零开始，教一台游戏本学会三国杀。
> 一张 RTX 4060，足够见证一个小模型从懵懂到会出牌。

---

## 序

打牌这件事，人类练了很多年。

从街角牌摊到网络对局，从手写攻略到棋牌 AI——我们总想让机器学会"判断"。而三国杀，恰好是一个足够复杂、又足够有趣的棋盘：身份、距离、手牌、技能、时机，每一步都藏在信息和运气之间。

**SGSZero** 就是这个念头的产物：不调用任何现成的棋类引擎，不依赖云端算力，只在一台普通的 Windows 笔记本上，从一张空白的网络出发，用对局本身教会它出牌。

名字致敬 [DouZero](https://github.com/kwai/DouZero)——斗地主从零开始。而这一次，轮到三国杀了。

## 这个项目是什么

SGSZero 是一套"从零训练三国杀出牌 AI"的完整管线：

- **训练场**：开源引擎 [无名杀](https://github.com/libnoname/noname)，一个 Electron 打包的三国杀实现，内置规则完整、可注入脚本；
- **数据来源**：`scripts/bot.js` 注入无名杀，让内置强 AI 自己跟自己打，逐手记录"局面 + 决策"，攒成监督学习的数据集；
- **训练策略**：SFT 模仿学习打底（先学会像高手那样出牌）→ 自对弈 PPO 强化学习突破（再学会赢）；
- **模型规模**：1~5M 参数，没有像素、没有自然语言，输入就是牌局状态本身，一张消费级显卡即可跑通全流程。

## 路线图

```
采数据(SFT标签) → SFT热启动 → 自对弈PPO → MCTS
    ↑              ≥85%一致率      胜过规则AI     可选
```

- **数据**：无名杀 `test_game` 极速全自动对局，只记"状态 + 动作"，不做任何人工标注
- **SFT**：先模仿，再谈超越。动作一致率达到 85% 即视为热身完成
- **PPO**：策略池 + 对手课程，让模型在对弈里自己找到更强的打法
- **评估**：以无名杀内置强 AI 为标尺，每 5k 步打 100 局对照
