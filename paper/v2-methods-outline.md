**原计划（已放弃）**：「发现 argmax 塌陷 → 学分布（RL）就修好了」。


照原骨架写，Introduction 说「别锁死 argmax」，Results 说「argmax 才对」，
两页就能被看穿。

**改后的主贡献（四条，均为方法学，不依赖强 AI 是否做成）**：

1. **拆解一个反直觉现象**：高准确率（80.9%）为何对应低于随机的整局胜率（44%），
   并说明「取最大值」在两种训练目标下作用相反。
   ⚠️ 44/66 是 11-01 旧口径，**5.4 重测前不得作为核心结论**，见 §5.4。
2. **一套可复现的卡牌 RL 评估协议**：**27 条**实测陷阱（阶段 2 的 14 条 +
   M3 的 13 条），每条含现象 / 实测量 / 判据 / 修复。这是本项目最可被别人
   直接拿去用的部分。
3. **一批架构级负结果**：逐接口 + 单变量 + 固定对手 + 单轨迹 TD 为何整体不成立；
   TD bootstrap 的三层症状如何在换成 MC return 后消解；门控目标函数为何
   在数学上不改变 argmax 排序；M2 训练级负结果与 M3 一档负结果。
4. **等价候选折叠与信号密度诊断链（2026-11-10 新增）**：M1b 零槽间梯度 →

## 4. Method（**全节重写，11-02 骨架不可复用**）

### 4.1 状态编码与 LUPI
561 token、3 层 Transformer d=256、1.76M 参数；特权价值头训练时用、部署丢弃（图 1）。

### 4.2 阶段 1：监督学习
- 任务 A/B/C 分层；80.9% / 66.5%
- **LUPI 的部署陷阱**：直接喂规则引擎估值，验证集 83.9% → 部署 35.6%

### 4.3 阶段 2：DQN（最终配置，逐项与 11-02 骨架不同）
| 项 | 11-02 骨架 | 最终实现 |
|---|---|---|
| 动作选择 | `softmax(q/τ), τ∈[0.5,1.0]` | `tau=0 argmax`（部署同口径） |
| reward | `z + 0.1Δhp + 0.05Δhand` | `z×2 + 0.1(Δown_hp + Δenemy_hp)`，删 hand 项 |
| 动作空间 | 24 张牌 | **25 槽**（新增 pass） |
| 回报传播 | 1-step | **n-step 3** |
| 梯度密度 | `update_every=200` | **25**（336→~20000 步/轮） |
| 终局判罚 | 比血量 | **打到上限一律判农民赢** |
| batch | 256 | 128 + 等价样本量补偿（`2048 // bs`） |

**逐项写明为什么改**，每项配实测数字（reward 符号错误导致龟缩 7-9%、
Q 极差中位数 0.158 使温度调度全程等价均匀采样、6.6 万局只走 5280 步梯度、
pass 配对 +7.3pt CI 全正、n-step +6.3pt）。

### 4.4 阶段 3：M2 框架切换（写「切换了什么、为什么」，不写「成功了」）
- M1b 十轮坐实三层症状全是 TD bootstrap 的产物
- 换 MC return + 三锚自对弈 + REINFORCE 加权分类；后继价值整环去掉
- **实现缺陷序列（作为方法学素材）**：符号写反、负侧无下界、训练/部署温度不一致、
  锚构造错位、门控丢负样本
- 当前状态：出口判据未达成，5.5 留活口

### 4.5 评估协议（全文方法学核心）
配对同牌双跑 / argmax / A-A 100% / 六项必报 / stall 三态 /
跨代同 seed + 配对斜率 / 代理量与整局配对对账 / 跨运行换状态集复现 /
单步梯度符号断言 / 有界性扫描 / 护栏可失败性检查。

## 5. Experiments

### 5.1 数据与基线
13,536 条按 gid 切分；教师为 10,966 行手写规则 AI；
规则 AI 基线 46.7%（**须注明局数与 CI；1000 局基线仍欠**）。

### 5.2 任务 A / B
80.9%（多数类基线 74.4%）；端到端 66.5%；V(s) 消融未通过，
诚实写法是「提升来自扩展候选集，不来自价值函数」。

### 5.3 统一 argmax 口径下的进步曲线
```
v2 19.3%  →  v4 13.3%  →  v5 35.7%  →  v6 48.0%
规则 AI 46.7%，diff -1.3pt，CI [-7.7, +5.1]，t = -0.41
```
- **v4 倒挂必须注明「Q 膨胀 artifact」**（p90=5.1 vs reward ±2；
  采样口径下 v4 反而是全场最高的 28.7%，argmax 直接暴露）
- 只写「统计上无法区分」，完整列 CI 与 t，禁止写「超越/打赢」

### 5.4 Argmax Collapse（**核心；重测前不得撰写**）
现状：四趋势 `top-1 44% / top-2 66% / top-3 62% / top-5 63%` 是
11-01 各 100 局、文档自述「混过路径」、中位轮数未记录、且承认 V(s) 消融未通过的旧口径。

**重测协议**（约 1 小时，训练侧执行）：
```
配对同牌双跑 / argmax / max_rounds=100 / stall 判罚一致 / A-A 100% / 六项必报
四配置各 300 对，补记中位轮数与 stall 率
判据：44 vs 66 差距方向仍在 → 5.4 可写
      差距塌掉或翻转       → 核心现象重新定性，v2 换题
```
**绝不放进同一张图或同一段推论**：`19.3/13.3/35.7/48.0`（argmax 口径）
与 `44/66`（11-01 旧口径）不可混用。

## 6. Analysis（材料最齐，可先写）

- **argmax 作为 Q 质量探针**：v4 采样 28.7%（全场最高）vs argmax 13.3%（全场最低），
  Q 膨胀 p90=5.1；温度采样会系统性掩盖价值函数缺陷
- **监督/RL 的 argmax 反差**（必须在正文显式统一）：
  监督目标学「教师动作分布」，取 max 锁死在「最像教师」那张；
  RL 学 Q 值，取 max 本就是正确用法。同一操作在两种训练目标下作用相反，
  说明问题不在「取最大值」，在训练目标错位
- **为什么模仿在对抗评估下现原形**：taskB 8.3%、taskC -6.3pt（CI 全负）；
  respond 91.8% 是常数、其余接口多为确定性硬编码
- **M1b 三层根因**：无动作项回报 / `q_sa=mean` 无槽间梯度（R8 梯度诊断：
  被弃槽梯度完全相等、保留槽恒 0）/ 后继价值恒定
- **门控为何不改变排序**：只学赢局 + 赢局 chosen 本就是 argmax +
  CE 只抬已选 ⇒ 代内 ρ≈1，logit 幅度在动但相对顺序不动
- **规则 AI 是 if-else 不是强基线**：这决定了「打平」的分量

## 7. Limitations

- 只做 2v1 斗地主模式，未做 8 人身份场；只训练地主身份
- **agent 只控制 9 个接口中的 1 个**，48% 是架构天花板不是能力天花板
- 对手是同引擎内手写的确定性规则 AI，赢了也证明不了「更强」
- 教师规则 AI 与 agent 共享引擎与对手逻辑
- 44/66 旧口径未重测；规则 AI 基线局数不足
- M2 / 自对弈 / 规模化均已按负结果收口，**本文不主张已达成强 AI**
- M3 的 35000 局锚点只覆盖候选级决策；主尺 CI 半宽由不一致对数决定，
  不由训练局数决定，因此延长训练无法缩小该区间
- 老师为确定性硬编码规则 AI（多数接口常数、恒选第 0 张），
  标签熵低是环境/信号来源的限制，不是模型容量限制
- 训练侧代码（`src/` / `engine/`）未公开，复现依赖本文与结果文档的口径描述
- 单卡 4060 Laptop，规模远小于 DouZero 原论文
